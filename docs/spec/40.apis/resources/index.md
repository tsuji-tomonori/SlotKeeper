# resources

| API | operationId | 業務概要 |
|---|---|---|
| [create_resource](create_resource/index.md) | `createResource` | 管理者が予約対象の資源を登録する。 |
| [get_resource_schedule](get_resource_schedule/index.md) | `getResourceSchedule` | 資源と日付を指定して予約済み時間帯を取得する。 |
| [list_resources](list_resources/index.md) | `listResources` | 予約できる資源の一覧を取得する。 |
| [update_resource](update_resource/index.md) | `updateResource` | 管理者が資源を編集または無効化する。 |
