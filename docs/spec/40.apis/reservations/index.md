# reservations

| API | operationId | 業務概要 |
|---|---|---|
| [cancel_reservation](cancel_reservation/index.md) | `cancelReservation` | 本人または管理者が開始前の予約を取消す。 |
| [create_reservation](create_reservation/index.md) | `createReservation` | 資源・開始・終了・目的を指定して自分名義の予約を作成する。 |
| [get_reservation](get_reservation/index.md) | `getReservation` | 本人または管理者が予約の詳細と操作履歴を取得する。 |
| [list_reservations](list_reservations/index.md) | `listReservations` | 自分の予約を日付・状態で絞り込んで取得する。 |
